# Victor | Makyneta

Site institucional desenvolvido para a marca Victor e Makyneta.

## Informações do projeto
- Tipo: landing page estática
- Tecnologias: HTML, CSS e JavaScript
- Objetivo: apresentar a marca, o coach, conteúdos, galeria e contacto de forma profissional e visualmente orientada para fitness

## Estrutura do projeto
- `index.html` — página principal
- `404.html` — página de erro 404
- `assets/scripts/main.js` — interações e comportamento dinâmico
- `assets/styles/main.css` — estilos principais
- `assets/styles/404.css` — estilos da página 404
- `assets/images/` — imagens do projeto

## Como visualizar localmente
1. Abra o projeto em um servidor local.
2. Pode usar o comando abaixo na pasta do projeto:

```bash
python3 -m http.server 8000
```

3. Acesse no navegador:

```text
http://localhost:8000
```
